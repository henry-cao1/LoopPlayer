# LoopPlayer

A minimal Windows desktop player that loops the body of a music track seamlessly — built for background music at meetings, rehearsals and events.

It plays the intro once, loops the chosen body section indefinitely, and plays the outro exactly once when the meeting starts, so the music ends naturally instead of being cut off mid-bar.

## Download

Grab the latest Windows build from the [Releases](https://github.com/henry-cao1/LoopPlayer/releases) page:

- `LoopPlayer-Portable-1.6.1-x64.exe` — portable, no installer, no admin rights, no writes outside the app's data folder. Put it anywhere (even a USB stick) and double-click to run.

## Quick start

1. Launch the portable exe. A demo track is bundled, so you can try everything immediately.
2. Click a track in the music library (the ♪ icon in the top-left menu) or use **Open audio** to load your own file.
3. The app analyses the file and marks three sections on the waveform: **entry** (blue), **body / loop** (green) and **outro** (amber).
4. Drag the green handles (or type timecodes in the sidebar) to fine-tune the loop boundaries. Drag the blue marker to set where the entry starts.
5. Press **Space** to start looping: the entry plays once, the body loops forever and the intro / outro are not repeated.
6. When the meeting begins, click **Start now · trigger** or press **Enter**. By default the current loop finishes before the outro plays; you can change that in Advanced settings. You can also arm a countdown or a specific clock time in the sidebar.
7. Click **Finish setup** once the in / out points look right. The track is then remembered, and a single click in the library starts the loop directly next time.

### Notes on playback

- Clicking anywhere on the waveform seeks there: the entry section starts from that point, the body loops, the outro plays once to the end.
- Tracks that have not been configured yet always start from the beginning of the file (0 s), not from the auto-detected entry point, so you can listen while adjusting.
- **Preview** plays linearly from the current position without looping; press it again to stop. After a full preview the track is marked as configured.
- The loop wrap uses a 16 ms equal-power crossfade, so there is no click or gap at the seam.
- Entry and outro fades are on by default (a smooth volume rise over the entry, a smooth fade-out at the end of the outro).
- If the music stops playing for a while and the pointer is away from the waveform editor, the window turns into a live line-art visualiser after one minute; move the mouse to return.

## Advanced settings

Open from the top-left menu (**Advanced settings…**):

| Setting | Default | What it does |
| --- | --- | --- |
| Music library folder | `%APPDATA%\LoopPlayer\music` | Folder scanned by **Scan music folder**; **Change…** picks a new one |
| Wait for the current loop to end before the outro | On | Meeting start / timed trigger waits for the running loop to finish |
| Nudge tempo (0.9–1.1×) before a timed trigger | Off | Slightly changes speed so the loop ends on the requested moment |
| Idle line-art view | On | 1 minute of inactivity while playing switches to the visualiser |
| Fade in over the entry, fade out at the end of the outro | On | Smooth volume ramp instead of hard starts / stops |
| Bass / treble balance across the seam (beta) | Off | Experimental. Session only — always starts unchecked after a restart |

Exit rules, cue files and other details are described in the in-app **How to use** dialog.

## Files and data

- Settings: `%APPDATA%\LoopPlayer\settings.json`
- Library list and annotations: `%APPDATA%\LoopPlayer\library.json`, `annotations.json`
- Cue files (**Export / Import setup**) are plain JSON, so a setup can be moved between machines.

## Build from source

Requirements: Node.js 18+ and the usual Electron build toolchain.

```bash
npm install
npm run dev      # renderer with hot reload
npm run start    # build + run the packaged-style app
npm run dist     # Windows portable exe in release-win-*/
```

The demo track and the app icon are generated by `tools/gen_sample.py` and `tools/gen_icon.py`, so the repository contains no third-party audio or artwork.
